# 🖐️ เกมมือวิเศษ ตอบคำถาม — Body-motion Quiz Game for Kids

เกมตอบคำถามแบบ **เคลื่อนไหวร่างกาย** สำหรับเด็กอนุบาล/ประถม เปิดกล้องหน้า เด็กยกมือ
แล้ว **เอื้อมมือไปค้างบนคำตอบ** จนวงแหวนวิ่งครบ = เลือกข้อนั้น เลียนแบบเกมที่ครูใช้เปิดก่อนเข้าบทเรียน

> ไฟล์เดียวจบ `index.html` (vanilla JS, ไม่มี build tool) — เปิดได้ทันทีบน Chrome/Edge

## ✨ ความสามารถ
- **โหมดครู** — สร้าง/แก้ไข/ลบชุดข้อสอบ ใส่ได้ทั้งข้อความและรูปภาพ, ตัวเลือก 2–4 ข้อ, เลือกข้อถูก
  ตั้งค่าเวลาต่อข้อ/คะแนน/เวลาค้างมือ/สลับลำดับ, **Export / Import เป็นไฟล์ JSON**
- **โหมดเล่น** — กล้องหน้า (mirror) + ตรวจจับมือด้วย **MediaPipe Hands** วาดโครงมือทับภาพ
  เลือกคำตอบด้วย **Dwell (ค้างมือ)** หรือ **Pinch (หนีบนิ้ว)**
- คะแนน + เวลานับถอยหลัง + เสียง + เอฟเฟกต์ถูก/ผิด + หน้าสรุปผล (ดาว)
- เก็บข้อมูลด้วย `localStorage` — ไม่ต้องมี backend
- มาพร้อมชุดตัวอย่าง 3 ชุด (สี / ผลไม้ / นับเลข) กดเล่นได้ทันที

## 🚀 วิธีใช้
1. เปิดผ่าน **GitHub Pages** หรือ `https://` (กล้องต้องการ secure context — เปิด `file://` ตรงๆ กล้องจะไม่ทำงาน)
2. กด **เริ่มเล่น** → อนุญาตกล้อง → ยกมือเอื้อมไปค้างบนคำตอบ
3. ครูสร้างข้อสอบเองได้ที่ปุ่ม **สร้างชุดข้อสอบ**

## 🔧 เทคนิค
- MediaPipe Hands (รุ่นคลาสสิก `@mediapipe/hands` + `camera_utils`) โหลดผ่าน CDN
- พิกัดนิ้วถูก mirror ด้วย `(1 - x) * innerWidth` ให้ตรงกับวิดีโอที่กลับด้าน
- Dwell สะสมเวลาใน `requestAnimationFrame` ทนต่อ frame jitter
